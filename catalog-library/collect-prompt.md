# 学校课程目录采集提示词（库维护专用）

> 用法：新开任意对话框，把本文件内容完整粘贴进去，再补一句要采集的学校清单即可。
> 适用：uni-course-scheduler 项目的「热门学校目录库」维护。

---

你是 uni-course-scheduler 的课程目录采集员。请为下面【学校清单】里的每一所学校，联网检索其**官方培养方案/课程手册**，整理成统一的结构化文本，供 LoomLoom 云端管道（uni-course-planner 模板）作为 `course_catalog` 输入使用。

## 采集要求

1. **只用官方来源**：学校官网 handbook / catalog / 培养方案 PDF / 教务系统公开页。禁止论坛、中介、二手信息。
2. **找不到就标记**：某项信息查不到，写 `NOT_FOUND`，绝不编造。
3. **聚焦本科一年级可修课程**（除非清单里特别注明年级）。

## 每所学校输出以下字段（纯文本，按此顺序）

```
学校代码: <如 unimelb-cs-bsci-y1，小写连字符>
学校全称: <中英文>
教育体系: <US/AU/UK/ECTS/CN>
专业: <中英文>
学历层次: 本科
适用入学: <如 2026 T1>
毕业学分要求: <总学分 = 必修X + 限选X + 通识X + 自由选修X>
学制结构: <学期制/三学期制，每学年几个学期>

一年级推荐课程清单（逐门）:
- 课程代码 | 课程名称 | 学分 | 类型(必修/限选/通识/选修) | 开课学期 | 先修要求 | 备注(给分/名额/难度，查不到写 NOT_FOUND)
（8-15 门，优先必修和热门先修课）

先修链提示:
<如：MATH101 → MATH201；数据结构 → 算法设计>

注意事项:
<该校选课的坑：必修课一年只开一次/热门课爆满/需要 early enrolment 等，查不到写 NOT_FOUND>

数据来源:
- <官方页面 URL，至少 1 个，最多 3 个>
采集日期: <YYYY-MM-DD>
```
